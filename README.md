## 🚀 Featured Production Systems

### 1. DIZCLSR — Financial Disclosure Intelligence Platform
- **Focus:** Backend infrastructure for processing, extracting, linking, and analyzing corporate disclosures from BSE/NSE.
- **Document Engine:** Python-based module converting unstructured disclosure documents into structured JSON without containing business logic.
- **Separation of Concerns:** Pure extraction isolated from SEBI Regulation 30(11) business validation rules.

### 2. CP-KYC — AI-Powered KYC & Compliance Automation
- **Focus:** Enterprise compliance platform automating corporate research & KYC workflows via intelligent agents, web data extraction, document processing, and structured data pipelines.
- **Verified Metrics:**
  - `40%` FastAPI response-time improvement
  - `70%` reduction in manual data collection
  - `50%` improvement in data accuracy
  - `<3 min` KYC verification turnaround

### 3. Device Automation & Orchestration Infrastructure
- **Focus:** Automation infrastructure for orchestrating physical Android devices, application workflows, provisioning, scheduling, verification, monitoring, and failure recovery.
- **Architecture:** Orchestrator → Parallel Device Workers → ADB/UI → Verification → Retry / Recovery → Reporting.
